## はじめに

個人開発している蔵書管理サービスで PWA 対応をしていて、一般ユーザー向けには「ホーム画面に追加すると便利ですよ」という趣旨の記事をブログの方に書いたことがあります。

ただ、あれは完全に「使う側へのお勧め」目線の記事でした。今回は逆に、作る側として PWA と付き合ってみて実際どうだったか、を正直に書いてみようと思います。結論を先に言うと、「勧める価値はあるけど、過度な期待はしない方がいい」というのが素直な感想です。

## そもそも PWA とは

PWA（Progressive Web App）は、普通の Web サイトに一定の実装（マニフェストファイル・Service Worker あたり）を足すことで、ホーム画面に追加したり、オフラインでもある程度動かせたり、通知を送れたりするようにする仕組みです。

ネイティブアプリのように「ストアでインストールしてもらう」のではなく、「普段使っているブラウザの延長線上で、アプリっぽい体験を提供する」というのがコンセプトです。ユーザー側からすると、以下のようなメリットがよく語られます。

- インストール不要ですぐ試せる（URL を開くだけ）
- ストア審査を挟まないので、対応さえしていればすぐ「アプリ化」できる
- ホーム画面に置けるので、ブラウザのタブに埋もれず再訪しやすくなる
- 通信環境が悪くても、ある程度は表示・操作ができる

一般ユーザー向けの記事では、主にこの「気軽に始められて、ホーム画面からすぐ開ける」という部分を推した内容にしました。ここまでが前提で、ここからが作る側として実際どうだったか、という本題です。

## ブラウザ・OSごとの体験差はまだまだある

PWA は仕様上「どのブラウザでも動く」ことになっていますが、実際にホーム画面に追加してもらうまでの体験は、環境によってかなり温度差があります。

- **Android Chrome**：一番素直です。条件を満たせば「ホーム画面に追加しますか？」のバナーが自然に出てくれるので、こちらから頑張って誘導しなくても気づいてもらいやすい環境です。
- **iOS Safari**：ここが一番苦労するポイントです。自動のインストール促進バナーのようなものは基本的になく、「共有ボタン → ホーム画面に追加」という手順をユーザー自身が知っている前提になります。一般ユーザー向けの記事を書いた動機も、正直ここの分かりにくさが大きいです。
- **デスクトップ（Chrome / Edge）**：アドレスバー付近にインストールアイコンが出るのでそこそこ分かりやすいですが、そもそも「デスクトップでアプリ化する」という発想自体がユーザーに馴染みが薄く、気づいてもらえないことが多い印象です。

「対応してます」と一言で言っても、実際にユーザーがそれを体験するまでの距離は環境ごとに全然違う、というのが最初に痛感したことでした。

## 「ネイティブアプリっぽさ」はどこまで本物か

ホーム画面に追加してもらえた後の話です。アイコンをタップして起動すると、アドレスバーが消えて全画面で立ち上がるので、見た目の第一印象はかなりネイティブアプリに近いです。ここは素直に良い体験だと思います。

ただ、細部を見ていくと「やっぱりブラウザなんだな」と気づく瞬間もそれなりにあります。例えば OS 標準の共有シートとの連携や、通知まわりの挙動は、ネイティブアプリと全く同じというわけにはいきません。特に iOS 側は制約が多く、機能によっては「対応はしているが、ネイティブアプリほど滑らかではない」という着地になりがちです。

なので、期待値としては「軽量なネイティブアプリ」ではなく、「常駐しやすくなったブックマーク」くらいに捉えておくのが実態に近いと感じています。

## 個人開発で PWA、やる価値はあるのか

正直なところ、実装コストはそこまで重くありません。すでに Web アプリとして動いているものに、最低限の対応を足すだけであれば、大掛かりな作り直しは不要です。

その上でやる価値があるかというと、個人的には「ある」派です。理由は主に2つです。

1. **継続利用のハードルが下がる**：ブラウザのタブに埋もれず、ホーム画面から直接開けるようになるだけで、再訪率には無視できない差が出ている実感があります
2. **ストア審査が要らない**：ネイティブアプリのような審査待ちやリジェクトのリスクなしに、いつでも好きなタイミングで更新をリリースできるのは、個人開発者にとって地味に大きいメリットです

一方で、「PWA対応さえすればネイティブアプリ並みの体験になる」という過度な期待は禁物です。あくまで Web の延長線上にある便利機能、くらいの温度感で導入するのがちょうど良いと思っています。

## まとめ

- ホーム画面への追加体験は、ブラウザ・OSごとにまだ結構な差がある（特に iOS が鬼門）
- 起動後の見た目はネイティブアプリに近いが、細部は「やっぱりブラウザ」だと気づく瞬間もある
- 実装コストの割にリターンはあると感じているので、個人開発でも導入する価値はある

一般ユーザー向けにPWAを勧める記事を書いた身としても、作ってみた結論は変わらず「対応する価値はある」でした。ただ、期待値のすり合わせは大事だな、というのが今回の気づきです。
